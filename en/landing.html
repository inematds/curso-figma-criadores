The Luz de Rua case

Tainá, a 32-year-old photographer, and Álvaro, a 61-year-old guide, create pieces for a fictional photo walk. The images were created with Codex. The layouts explain choices; they are not screenshots of the Figma interface.

Open the source image and plan for the four pieces. You will create your own working file during the lessons.

How to study

You need a computer, browser, and Figma account with editing permission. The layouts use basic features in one file and one page. Check your account limits. A phone is useful for reading and review; production takes place on a computer.

The lessons include ten-minute practices. The full series takes additional time: set aside 8–12 hours for study and production. Completion requires four checked PNGs and an editable .fig copy. A task missing a required file remains pending.

Progress stays in this browser. Save a copy through the journey panel. The course contains reading, examples, and activities; it is not recorded video lessons.
