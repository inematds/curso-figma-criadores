Alinhe pelo mesmo início e repita os espaços

Você consegue organizar três objetos com alinhamento e intervalos regulares.

Objetos quase alinhados criam ruído. Use os controles para conferir o que o olho percebeu.

Em 1 minuto

  1. Seleção: três objetos do mesmo conjunto
  2. Intervalo de teste: 24 unidades
  3. Margem inicial do texto: 64 unidades

1A seleção define o alinhamento

Selecione três objetos do mesmo quadro, mantendo Shift ao clicar.

Use Align left para alinhar pelo início.

Confira quais objetos ficaram selecionados.

Quando apenas um está marcado, o alinhamento pode usar o quadro pai como referência.

Para treinar, use três retângulos de teste fora da capa.

Coloque-os numa coluna, selecione os três e use Tidy up ou distribuição vertical.

Observe a distância entre eles.

Ajuste para 24 no campo de espaçamento quando disponível.

Tainá seleciona só os objetos que precisam compartilhar o intervalo.

2Margem é parte da composição

Na capa, reserve uma margem inicial de 64 unidades para a região de texto.

Ela é uma escolha deste exercício, não um padrão universal.

Confira se título, apoio e assinatura respeitam o mesmo início.

Use guias visuais e os campos de posição para ajustar.

Não aplique organização automática a toda a peça sem olhar.

O programa não conhece a importância de cada elemento.

Tidy up pode mudar posições além do desejado.

Teste numa cópia ou desfaça se a composição perder sentido.

Álvaro confere a margem da capa depois do teste separado.

3Confira a decisão pelo uso

Selecionar os objetos corretos, alinhar e conferir os intervalos.

Álvaro usa a ficha para conferir: margem inicial do texto: 64 unidades.

Teste-se

Tidy up alterou a composição inteira de forma indesejada. O que fazer?

Se travou aqui, é normalSe os controles não aparecerem, confira se há vários objetos selecionados. Alinhamento e distribuição são ações diferentes.
