Planeje uma capa e três páginas

Você consegue escrever o conteúdo de quatro peças antes de diagramar.

Sem um roteiro, cada página vira um novo começo. Defina a função de cada uma antes de duplicar o desenho.

Em 1 minuto

  1. Capa: apresentar Luz de Rua
  2. Páginas: luz, detalhe e série
  3. Fixos: cores, letras e assinatura

1Quatro peças, uma sequência

A capa apresenta Luz de Rua.

A página 1 orienta observar a luz.

A página 2 pede escolher um detalhe.

A página 3 convida montar uma série.

Cada página recebe uma ideia principal e uma frase de apoio.

Evite repetir a mesma promessa nas quatro.

Escreva primeiro numa nota.

Exemplo da capa: Luz de Rua; um passeio para treinar o olhar.

Página 1: Olhe a luz; observe onde a sombra muda.

As outras páginas podem usar Escolha um detalhe e Monte sua série.

Tainá escreve o roteiro antes de escolher o enquadramento.

Abrir imagem fonte e roteiro das quatro peças.

2Defina os elementos que vão se repetir

Escolha uma cor de fundo, uma de texto e uma de destaque.

Reserve um lugar para o nome e para a numeração.

No exercício, usaremos creme, azul petróleo e ocre.

Essas escolhas ajudam a reconhecer a família sem exigir imagens idênticas.

Quem vem do Canva pode pensar em uma página do desenho.

No Figma, cada peça ficará num quadro chamado frame.

Uma página do arquivo pode conter muitos quadros.

Essa diferença evita criar vários arquivos para um único carrossel.

Álvaro distingue a página do arquivo dos quatro quadros que ela contém.

3Confira a decisão pelo uso

Dar uma função e uma chamada a cada quadro, mantendo uma família visual.

Álvaro usa a ficha para conferir: fixos: cores, letras e assinatura.

Teste-se

No Figma Design, como organizar quatro peças do mesmo carrossel?

Se travou aqui, é normalUse os quatro títulos do exemplo se estiver sem ideia. Acrescente uma frase simples para cada um.
